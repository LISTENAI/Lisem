# ARCS 固定芯片 ROM

这些二进制是芯片模型的固定发布资产，构建时按 `manifest.json` 校验大小与
SHA-256，转换成只读数组静态链接进 QEMU；无运行时文件选择或替换入口。
ROM 不属于实例 Flash／OTP，不受 LPK 写入、全片擦除或芯片复位影响。

固定 ROM 的地址、大小与哈希如下：

| ROM | 全局地址 | 大小 | SHA-256 |
| --- | --- | --- | --- |
| AP | `0x00000000` | 65,536 字节 | `8f07301b46b34336022c079cf479beaeae960f6cb14f08cc2a478a4264d10489` |
| CP | `0x00200000` | 32,768 字节 | `b1710a8f7968399788bb191c34872c2640c1bf62c00400ad25dcc1f2027ee262` |

AP 下载协议版本为 `0x05`，该值不代表硅片修订号。大小与地址依据 LS26
User Manual 1.1.1／Fig.1.1。ROM 字节以 `manifest.json` 中的哈希为准。

AP 入口为 `0x0 → 0x1c0`，CP 默认复位向量为 `0x00200000`。启动与串口下载
方式见[使用说明](../../../docs/usage.md#串口烧录)。
